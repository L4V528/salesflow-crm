# 变更申请单（CRF）模板

> 模板用途：AI 在需求/设计变更时产出 `CR-xx`，支撑 SKILL.md 1.5 变更闭环与 10-需求变更管理与基线记录。原则：任何口头改动都补一张单（拒绝范围蔓延）。占位符 `【】` 填充后删除。

---

## 变更申请单（Change Request Form）

| 字段 | 内容 |
| --- | --- |
| 变更单编号 | CR-【YYYYMMDD】-【序号】 |
| 提出人 | 【张三 / 客户 / 干系人】 |
| 提出日期 | 【YYYY-MM-DD】 |
| 提出途径 | 【会议 / 邮件 / 访谈 / 工单】 |
| 关联文档 | 【05-SRS v1.0 / 11-架构设计】 |
| 关联需求 | 【FR-3-02 / 原 NFR-x】 |
| 紧急程度 | 【高（影响上线）/ 中 / 低】 |

### 1. 变更类型（单选 / 多选）
- [ ] 需求新增（新增功能或 NFR）
- [ ] 需求修改（调整既有权限/阈值/流程）
- [ ] 需求删除（范围裁剪）
- [ ] 设计调整（架构/数据/接口）
- [ ] 其他：【】

### 2. 变更内容（改前 → 改后，必须可对比）
| 项 | 变更前 | 变更后 |
| --- | --- | --- |
| 【审批阈值】 | 折扣率≥25% 触发两级 | 折扣率≥30% 触发两级 |
| 【影响需求】 | FR-3-02 原规则 | FR-3-02 新规则 BR-QUOTE-APPROVAL v1.1 |

### 3. 变更原因（为什么要改）
【财务合规要求两级审批门槛上移，原 25% 过宽易产生高频审批；依据可行性报告(02)风险 R-2。】

### 4. 影响分析（逐项评估，禁止只写"无影响"）

| 维度 | 影响说明 | 量级 |
| --- | --- | --- |
| 范围 | 影响 SRS FR-3-02、数据库枚举、用例集 3 条 | 中 |
| 进度 | 设计+编码+用例回归 +0.5 天 | 低 |
| 成本 | 无额外人力/采购 | 无 |
| 质量 | 提升合规一致性，降低误批 | 正向 |
| 风险 | config 集中故改动局部，回归可控 | 低 |
| 追溯 | 需同步更新 09-RTM 对应行状态 | 中 |

### 5. 优先级与处置建议
- 优先级：【高 / 中 / 低】
- 建议：【批准并纳入 v1.1 / 驳回维持 v1.0 / 延期至下版本】
